# Cara Buat GitHub Token untuk Paduka Alwiy

## Langkah-langkah:

1. **Buka GitHub Settings**:
   - URL: https://github.com/settings/tokens
   - Atau: GitHub → Profile (kanan atas) → Settings → Developer settings → Personal access tokens → Tokens (classic)

2. **Generate New Token**:
   - Klik "Generate new token (classic)"
   - Note: "Railway Deploy iBio"
   - Expiration: "No expiration" atau "90 days"

3. **Pilih Permissions** (centang ini):
   - ✅ `repo` (Full control of private repositories)
     - Ini akan auto-centang semua sub-options

4. **Generate Token**:
   - Scroll ke bawah
   - Klik "Generate token"
   - **COPY TOKEN SEKARANG!** (hanya muncul sekali)
   - Format: `ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

5. **Berikan ke Saya**:
   - Paste token di chat
   - Saya akan push semua file ke repo Paduka Alwiy
   - Setelah selesai, Paduka Alwiy bisa delete token jika mau

## Contoh Token:
```
ghp_1234567890abcdefghijklmnopqrstuvwxyz123
```

## Keamanan:
- Token ini seperti password
- Jangan share ke orang lain
- Bisa di-delete kapan saja di GitHub settings
- Saya hanya pakai untuk push file deployment
