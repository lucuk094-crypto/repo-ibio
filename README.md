# Bio Link - Paduka Alwiy

Bio link website dengan desain modern menggunakan Tailwind CSS.

## Features

- ✅ Responsive design
- ✅ Modern gradient colors (Pink & Violet)
- ✅ Smooth animations
- ✅ Social media icons
- ✅ Multiple link buttons
- ✅ Easy to customize

## Deploy ke Vercel

1. Push ke GitHub
2. Import di Vercel
3. Deploy otomatis!

## Customize

Edit file `index.html` untuk mengubah:
- Nama
- Bio/deskripsi
- Social media links
- Link buttons
- Foto profile

## Color Scheme

- Background: `#0d1224` (Dark blue)
- Primary: `#ec4899` (Pink)
- Secondary: `#8b5cf6` (Violet)
- Accent: `#16f2b3` (Cyan)
